# th_dnh_fix_fps (東方弾幕風 0.12m FPS改善パッチ)

東方弾幕風 0.12m を Windows 10 / 11 などのモダンOS環境で起動した際に発生する、フレームレート（FPS）の異常を解消するためのプロキシDLL（パッチ）です。

> ### 💡 このプロジェクトについて (Vibe Coding)
> 本プロジェクトの大部分は、バイブコーディングで開発しました。  
> こういうこともできるんだなー程度に見てください。不具合あったらごめんなさい :(

## 主な機能・解決する問題

1. **フルスクリーン時の500FPS暴走（高速化）の防止**
   - Windows 10/11環境でフルスクリーン起動した際に、DirectX 8の垂直同期が外れて数百FPS〜千FPS以上で爆走してしまう問題を防止し、正常な **60.0 FPS** に抑制します。
2. **ウィンドウモード時の56FPS頭打ち問題の解消**
   - ウィンドウモード起動時に、Windowsのタイマー遅延（スレッド切り替えオーバーヘッド）によってゲーム側の待機ループが長引き、56FPS前後で固定されてしまう問題を解消します。
   - 高精度タイマー（`QueryPerformanceCounter`）によるマイクロ秒精度のフレーム同期を行い、滑らかな **60.0 FPS** を維持します。
3. **完全非破壊・置くだけの簡単導入**
   - 既存の `th_dnh.exe` やデータファイルは1バイトも書き換えません。
   - DLLをフォルダに置くだけで機能し、削除すれば一瞬で元の状態に戻ります。
   - 外部ランタイム（VC++再頒布可能パッケージ等）を一切要求しない完全自己完結仕様です。

## 動作対象・前提条件

本パッチは **東方弾幕風 0.12m** 専用です。本パッチ単体では動作しません。
東方弾幕風本体をお持ちでない場合は、原作者様（mkm様）の公式サイトよりダウンロードしてください。

- 配布元: **と～ほ～GC** (mkm様)

## 導入方法

> [!IMPORTANT]
> 本パッチは既存ファイルを改変しませんが、予期せぬ不具合やセーブデータトラブル等に備え、**事前に弾幕風フォルダ全体のバックアップ（フォルダごとのコピー）を取っておくことを強く推奨します。**

1. リリース（またはビルド成果物）から以下の2つのファイルを取得します：
   - `d3d8.dll`
   - `d3d8_patch.ini`
2. 上記2ファイルを、東方弾幕風0.12mの実行ファイル（`th_dnh.exe`）が存在するフォルダ内にそのままコピー＆ペーストして配置します。
3. 通常通り `th_dnh.exe` を起動します。

---

## アンインストール方法

- 弾幕風のフォルダから `d3d8.dll`、`d3d8_patch.ini`（および生成された `d3d8_patch.log`）を削除してください。
- 元のファイル自体は改変されていないため、削除するだけで導入前の状態に戻ります。もし万が一動作が不安定な場合は、事前にとったバックアップから復元してください。

---

## 設定 (`d3d8_patch.ini`)

テキストエディタ（メモ帳など）で設定値を変更できます。

```ini
[Settings]
; 目標FPS（デフォルト: 60.0）
TargetFPS=60.0

; パッチ側の高精度タイマー制御を有効にするか（1: 有効, 0: 無効）
EnableFpsLimit=1

; フルスクリーン時にPresentationIntervalをIMMEDIATEに強制するか（1: 有効, 0: 無効）
; 1にすることでDirectX内部の垂直同期破綻を回避し、パッチ側で正確に同期します
ForceImmediate=1

; 動作ログ（d3d8_patch.log）を出力するか（1: 出力する, 0: 出力しない）
EnableLogging=1
```

## ビルド方法 (開発者向け)

外部SDKや追加ライブラリのダウンロードは不要です。Visual Studio (MSVC) がインストールされた環境でビルドできます。

```cmd
cmake -B build -A Win32
cmake --build build --config Release
```
ビルド完了後、`build/Release/d3d8.dll` が生成されます。
